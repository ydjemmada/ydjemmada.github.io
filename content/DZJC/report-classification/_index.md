Please include enough public evidence to verify the issue. Do not send private Google Scholar profile data, cookies, passwords, authentication codes, or private account information.

## Email Template Preview

```text
Journal title:
Print ISSN:
Electronic ISSN:
Article title (optional):
DOI (optional):

Displayed category:
Expected category:
Official DGRSDT/MESRS source URL:

Extension version:
Chrome version:
Operating system:

Google Scholar page URL (if public):
Screenshot attached: yes/no

Additional explanation:
```

## Evidence Tips

- Prefer official DGRSDT/MESRS source URLs.
- Include both print ISSN and E-ISSN when available.
- Hide personal information from screenshots.
- If the problem appears only on a private profile or signed-in page, describe the public journal metadata instead of sending private profile details.

## What Happens Next

Reports are reviewed against the bundled database and the official source evidence. If a correction is needed, it will be included in a future database and extension release.
