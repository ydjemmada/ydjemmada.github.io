Evidence Tips

  • Prefer official DGRSDT/MESRS source URLs.
  • Include both print ISSN and E-ISSN when available.
  • Hide personal information from screenshots.
  • If the problem appears only on a private profile or signed-in page, describe the public journal metadata instead of sending private profile details.

What Happens Next

Reports are reviewed against the bundled database and the official source evidence. If a correction is needed, it will be included in a future database and extension release.
