Support

Support and troubleshooting for DZ Journal Check.

For support, contact yahia.djem@gmail.com.

DZ Journal Check is independent and unofficial. Please do not send passwords, authentication codes, cookies, private Google Scholar account details, or private profile information.

Before Reporting A Problem

  • Confirm that DZ Journal Check is enabled in Chrome.
  • Confirm you are using the latest extension version.
  • Try searching by ISSN, E-ISSN, or DOI when a title match is unclear.
  • Check whether Google Scholar is showing a journal venue, repository copy, arXiv preprint, book, thesis, or incomplete metadata.
  • Refresh the page once if Google Scholar dynamically loaded results after the extension started.

What To Include In A Bug Report

  • Chrome version.
  • DZ Journal Check extension version.
  • Operating system.
  • Page URL where the problem occurred, if it does not expose private information.
  • Search query or public result URL.
  • Journal title.
  • Print ISSN.
  • Electronic ISSN.
  • DOI, if available.
  • Screenshot with personal information hidden.
  • Expected result and actual result.

Incorrect Classification Reports

For classification corrections, include:

  • Journal title.
  • ISSN.
  • E-ISSN.
  • Currently displayed category.
  • Expected category.
  • Official DGRSDT/MESRS evidence or source URL.
  • Screenshot showing the issue.
  • Page URL where the issue occurred, if public.

Use the classification correction page for a copyable template.

Troubleshooting

The badge does not appear

Google Scholar may not expose enough venue metadata, or the result may be a repository copy, preprint, book, thesis, or ambiguous publication. In these cases, DZ Journal Check may show Unclassified or no journal category.

DOI lookup does not resolve

Crossref metadata may be missing, incomplete, temporarily unavailable, or blocked by network conditions. Try the journal title or ISSN in the popup.

Author statistics are partial

Google Scholar may limit or block profile page requests. When the extension cannot safely fetch all profile pages, it may mark statistics as partial.
